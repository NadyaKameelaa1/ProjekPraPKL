Selamat datang di projek JAVAST kami! 

JAVAST adalah sebuah website pemesanan hotel yang dikembangkan untuk mempermudah pengguna dalam mencari dan memesan akomodasi di berbagai kota di Jawa Tengah. Proyek ini mencakup fitur pencarian hotel, pemesanan kamar, pilihan metode pembayaran (E-wallet & bayar di tempat), serta sistem admin untuk mengelola data hotel, kamar, pemesanan, dan pendapatan. Dengan tampilan antarmuka yang modern dan sistem backend yang terintegrasi, JAVAST menjadi contoh penerapan teknologi web yang efisien dan fungsional dalam dunia perhotelan.

📁 Branch Overview
1. main: Berisi source code untuk Front-End dari website JAVAST. Di dalamnya terdapat tampilan antarmuka pengguna yang dirancang menggunakan teknologi web seperti HTML, CSS, dan JavaScript.
2. back-end: Merupakan branch versi lengkap dari proyek ini, yang mencakup Front-End dan Back-End secara utuh. Di branch ini, seluruh fitur website sudah terintegrasi, termasuk sistem login, manajemen data hotel dan kamar, pemrosesan pemesanan, serta pengelolaan pembayaran.
